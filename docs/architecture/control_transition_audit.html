04 / ISSUE REGISTER

现有问题分级

P0 是直接控制边界与停止一致性；P1 是状态/任务完成风险；P2 是检测和配置漂移；P3 是维护与操作员认知。这里不代表已修复。

P0Safety

两个进程级 motor writer，没有共享 lease

auto runner 与 manual app 都能独立构造 bot 并直接调用底盘。

OBSERVED CONSEQUENCE

进程内 lock 无法阻止另一个进程写入；“最后一次 set_car_motion”成为事实仲裁器，owner 无法审计。

07 / MIGRATION SEQUENCE

建议迁移顺序

先建立可观测、可验证的契约，再改变控制行为；不要继续针对单次 run 在原有交叉分支上加例外。

TYPED SNAPSHOT, NO BEHAVIOR CHANGE
增加 MissionState、ControlOwner、SafetyState、typed events 与 frame-level invariant telemetry；旧分支仍产生命令。
EXTRACT ONE ARBITER
把 race_runner 内联条件提取成纯 arbiter；输入 candidates/safety requests，输出 owner、command、override 与 reason；用现有测试和记录帧做等价验证。
UNIFY STOP LATCH
